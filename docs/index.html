🚀 Quickstart Guide

Publish a complete, server-authoritative Roblox idle tycoon in under 60 minutes.

  1. Download the latest .rbxlx release from GitHub.
  2. Open in Roblox Studio and publish to your Roblox Experience.
  3. Enable API Services under Game Settings -> Security.
  4. Run python3 tools/replace_ids.py to configure your Robux Developer Products & Gamepasses.
  5. Publish and share your game link!
# Run balance simulation locally
python3 tools/balance_sim.py --hours 6 --check

# Sync manifest to website
python3 tools/sync_site.py --site ../linacre-site-repo

⚙️ Engine Setup & Tools

Slime Factory Tycoon is structured around professional Roblox tooling:

  • Rojo: File-system to Roblox Studio sync engine.
  • Selene: Fast Luau linter enforcing strict type boundaries.
  • StyLua: Opinionated Luau code formatter.
  • GameConfig.luau: Single source of truth for all upgrades, zones, pets, and rebirth parameters.

📈 Economy & Pacing Strategy

The progression curve is mathematically tuned using an exponential growth model:

Cost = baseCost * (growth ^ level)

Growth parameters:

  • Upgrades growth: ~1.15 to 1.28
  • Rebirth cost growth: 4.5x per rebirth
  • First rebirth target time: ~21.8 minutes (10.8 minutes with 2x Goo pass)

🛡️ DataStores & Anti-Exploit Architecture

All game logic is 100% server-authoritative:

  • Session Locking: Prevents multi-server duplication bugs.
  • Receipt Idempotency: Prevents Robux purchase duplication on disconnects.
  • Bounded Tapping Rate: Max 20 clicks/sec server check mitigates autoclickers.

⚡ Performance Tuning

  • UI is 100% programmatically rendered without bloat instances.
  • Reduced motion & high contrast modes for mobile & lower-end devices.
  • Particle batching and memory management for low-end phone GPUs.
