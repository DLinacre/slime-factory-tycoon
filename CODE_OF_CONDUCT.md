# Code of Conduct

## The short version

Be decent. This is a small open-source project, not a battleground.

## Expected behaviour

- Assume good faith. Most disagreements are misunderstandings.
- Critique code, not people.
- Remember that a lot of Roblox developers are young and learning. "This is
  wrong" helps nobody; "this lets the client set currency, which an exploiter
  can forge — here's the server-side pattern" teaches someone something.
- Accept that maintainers may decline features. This project explicitly rejects
  work that doesn't improve retention, engagement, or revenue.

## Unacceptable behaviour

- Harassment, discrimination, or personal attacks of any kind
- Sexualised language or imagery — this project is tied to a platform with a
  large under-13 audience and that line is absolute
- Publishing others' private information
- Deliberately posting exploits intended to harm live games. Reporting a
  vulnerability in *this* template is welcome and encouraged; weaponising one
  against someone else's game is not.

## Reporting

Open a private security advisory, or contact the maintainer through
[linacre.site](https://www.linacre.site). Reports are handled confidentially.

## Enforcement

Maintainers may edit, hide, or delete contributions that breach this document,
and may block repeat offenders. Enforcement aims to be proportionate: a warning
first, unless the behaviour is severe.
