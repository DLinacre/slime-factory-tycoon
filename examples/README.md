# Examples

Small, copy-paste friendly extensions that demonstrate how to extend the template.

## How to use an example

1. Copy the `.luau` file into the appropriate `src/` folder
2. Restart Rojo (or rebuild)
3. The new file will be auto-discovered (for services) or used automatically (for content)

## Available examples

| File | Type | What it does |
|------|------|--------------|
| `CustomBoosterService.luau` | Service | Simple temporary server-wide multiplier |
| `SeasonalContent.luau` | Content | Example of adding a new season |
